# CloudNative-Shop

Production-style DevOps/Platform Engineering project for deploying and operating an e-commerce microservices application on AWS EKS.

## Goals

- Provision AWS infrastructure using Terraform
- Containerize microservices using Docker
- Run workloads on Amazon EKS
- Package Kubernetes deployments using Helm
- Build CI/CD pipelines using Jenkins
- Automate operational tasks using Python and Bash
- Implement monitoring, security, scaling, and troubleshooting
- Practice production incident scenarios

## Technology Stack

- AWS
- Kubernetes / Amazon EKS
- Terraform
- Docker
- Jenkins
- Helm
- Python
- Bash
- Git / GitHub

## Architecture

Developer → GitHub → Jenkins → Docker → Amazon ECR → Helm → Amazon EKS
